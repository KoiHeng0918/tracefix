# TraceFix 评测

目标：用黄金集证明系统效果，而不是凭感觉。

## 数据拆分

```text
dev      调 Prompt / 检索权重
test     每次 CI 回归
holdout  只在发版前跑，禁止调参
```

## 指标

- 检索：Recall@5、MRR@10
- 解析：异常类型准确率
- 诊断：根因准确率
- 忠实度：引用正确率、答案忠实度
- 不确定性：abstain 准确率、误答率
- 工程：P95 延迟、单次成本
