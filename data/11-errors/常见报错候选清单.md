## 1. ERR-SPRING-0001 Bean 找不到

- **分类**：spring
- **异常类型**：`org.springframework.beans.factory.NoSuchBeanDefinitionException`
- **典型消息**：`No qualifying bean of type 'com.demo.XxxService' available`
- **常见根因**：
  - 实现类没加 `@Service` / `@Component`
  - 实现类不在启动类的扫描包下
  - 接口有多个实现，注入时没指定 `@Qualifier`
  - 依赖模块没有被加载
- **排查步骤**：
  1. 看实现类有没有 Spring 注解
  2. 看启动类 `@SpringBootApplication` 的包范围
  3. 看接口是不是有多个实现
  4. 看依赖模块是否被引入
- **修复**：补注解、调整扫描包、用 `@Qualifier` 指定实现
- **验证**：应用启动成功，注入点不再抛异常
- **来源**：
  - https://kodejava.org/troubleshooting-common-errors-in-your-first-spring-boot-application/
  - https://blog.csdn.net/ashyyyy/article/details/146258768
- **状态**：待验证

## 2. ERR-SPRING-0002 端口被占用

- **分类**：spring
- **异常类型**：`java.lang.IllegalStateException`（外层可能是 `Web server failed to start`）
- **典型消息**：`Port 8080 was already in use`
- **常见根因**：
  - 上一个 Spring Boot 进程没停
  - 其他程序占用了 8080
  - 多个服务配置了同一个端口
- **排查步骤**：
  1. `netstat -ano | findstr :8080`
  2. 找到 PID，确认是哪个进程
  3. 停掉旧进程，或改 `server.port`
- **修复**：停掉占用端口的进程，或换端口
- **验证**：应用启动成功，`/api/health` 可访问
- **来源**：
  - https://blog.csdn.net/ashyyyy/article/details/146258768
- **状态**：待验证

## 3. ERR-SPRING-0003 数据源未配置

- **分类**：spring
- **异常类型**：`org.springframework.boot.autoconfigure.jdbc.DataSourceProperties$DataSourceBeanCreationException`
- **典型消息**：`Failed to configure a DataSource: 'url' attribute is not specified`
- **常见根因**：
  - `application.yml` 没配 `spring.datasource.url`
  - 配置放错 profile
  - 引入了 JDBC 依赖但没配数据源
- **排查步骤**：
  1. 检查 `spring.datasource` 配置
  2. 检查当前激活的 profile
  3. 检查是否真的需要数据源
- **修复**：补数据源配置，或排除自动配置（如果不需要数据库）
- **验证**：应用启动成功，数据源能初始化
- **来源**：
  - https://kodejava.org/troubleshooting-common-errors-in-your-first-spring-boot-application/
- **状态**：待验证

## 4. ERR-MYBATIS-0001 Invalid bound statement

- **分类**：mybatis
- **异常类型**：`org.apache.ibatis.binding.BindingException`
- **典型消息**：`Invalid bound statement (not found): com.demo.mapper.UserMapper.selectById`
- **常见根因**：
  - Mapper XML 的 `namespace` 和接口全类名不一致
  - XML 的 `id` 和方法名不一致
  - XML 没被扫描到（`mapper-locations` 配置错误）
  - Mapper 接口没被 `@MapperScan` 扫描
  - IDEA 没有把 XML 编译到 `target/classes`
- **排查步骤**：
  1. 对 namespace 和接口全类名
  2. 对 XML id 和方法名
  3. 检查 `mapper-locations`
  4. 检查 `target/classes` 下有没有 XML
- **修复**：对齐 namespace/id，补扫描配置，重新 build
- **验证**：调用 Mapper 方法不再抛 BindingException
- **来源**：
  - https://baomidou.com/reference/question/
  - https://cloud.tencent.com/developer/article/1992566
- **状态**：待验证

## 5. ERR-BUILD-0001 PaginationInnerInterceptor 找不到类

- **分类**：build
- **异常类型**：`java.lang.ClassNotFoundException` / `java.lang.NoClassDefFoundError`
- **典型消息**：`com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor`
- **常见根因**：
  - MyBatis-Plus 3.5.9 起把分页插件相关依赖拆成独立模块
  - 只引了 starter，没有引 `mybatis-plus-jsqlparser`
- **排查步骤**：
  1. 看 MyBatis-Plus 版本
  2. 看 `pom.xml` 是否有 `mybatis-plus-jsqlparser`
  3. 刷新 Maven 依赖
- **修复**：添加匹配版本的 `mybatis-plus-jsqlparser`，重新 build
- **验证**：分页插件类能加载，分页查询正常
- **来源**：
  - https://baomidou.com/plugins/pagination/
  - https://github.com/baomidou/mybatis-plus/issues/6561
- **状态**：待验证

## 6. ERR-MYSQL-0001 Access denied

- **分类**：mysql
- **异常类型**：`java.sql.SQLException`
- **典型消息**：`Access denied for user '{user}'@'{host}' (using password: YES)`
- **常见根因**：
  - 数据库密码错
  - 用户名错
  - 用户没有该库权限
  - 主机限制（`user`@`host` 不匹配）
- **排查步骤**：
  1. 核对 `application.yml` 的 username/password
  2. 用 MySQL 客户端手动登录
  3. 检查用户权限和 host
- **修复**：改对密码/用户名，或补权限
- **验证**：应用能建立连接，接口查询正常
- **来源**：
  - https://dev.mysql.com/doc/refman/26.10/en/common-errors.html
- **状态**：已有真实复现案例

## 7. ERR-MYSQL-0002 Communications link failure

- **分类**：mysql
- **异常类型**：`com.mysql.cj.jdbc.exceptions.CommunicationsException`
- **典型消息**：`Communications link failure`
- **常见根因**：
  - MySQL 没启动
  - 端口/主机不通
  - 防火墙/安全组
  - 连接超时
- **排查步骤**：
  1. `ping` / `Test-NetConnection` 检查主机端口
  2. 看 MySQL 是否监听
  3. 看防火墙/安全组
- **修复**：启动 MySQL、修端口/防火墙、补超时配置
- **验证**：应用能连上数据库
- **来源**：
  - https://dev.mysql.com/doc/refman/26.10/en/common-errors.html
  - https://repost.aws/knowledge-center/rds-mysql-access-errors
- **状态**：待验证

## 8. ERR-SPRING-0004 UnsatisfiedDependencyException

- **分类**：spring
- **异常类型**：`org.springframework.beans.factory.UnsatisfiedDependencyException`
- **典型消息**：`Error creating bean with name 'xxx': Unsatisfied dependency expressed through field 'yyy'`
- **常见根因**：
  - 依赖的 Bean 不存在
  - 循环依赖
  - 构造器注入参数不匹配
  - 配置类没生效
- **排查步骤**：
  1. 看 `Caused by` 最里层
  2. 看缺的是哪个 Bean
  3. 看是否有循环依赖
- **修复**：补 Bean、拆循环依赖、调整注入方式
- **验证**：应用启动成功，依赖注入正常
- **来源**：
  - https://kodejava.org/troubleshooting-common-errors-in-your-first-spring-boot-application/
- **状态**：待验证

## 建议先复现哪 3 条

1. **ERR-MYBATIS-0001 Invalid bound statement**：最常见，也最贴近你的项目。
2. **ERR-SPRING-0001 Bean 找不到**：Spring 基础，面试常问。
3. **ERR-SPRING-0002 端口占用**：最容易复现，几分钟就能做。

## 复现后怎么转成案例

每条确认后，用 `/case/import` 导入，字段按：

```text
caseNo / title / category / exceptionType / messagePattern /
techStack / versionScope / symptom / rootCause /
fixSteps / verification / source / sourceUrl / license / fingerprint
```

`source` 写“公开资料 + 自己复现”，`sourceUrl` 填上面的链接。  
`fingerprint` 先填 `tmp-...`，后面统一重算。
